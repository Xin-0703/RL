# DQN 课后练习参考答案

对应 [课后练习](exercises.md)。数值计算采用题目约定的损失与更新规则。

## 1. 即时奖励与 Q 值

不矛盾。Q 值包含未来折扣奖励。例如 $\gamma=0.7$，先得到 −2，下一步得到 +10 并结束：

$$
Q=-2+0.7\times10=5.
$$

## 2. 三个关键机制

- 经验回放：降低相邻样本相关性、提高经验复用率。
- 目标网络：使计算 TD 目标的网络参数暂时稳定。
- $\epsilon$-greedy：平衡探索未知动作和利用当前估计。

目标网络参数固定不意味着目标值相同。不同样本的奖励、下一状态、终止标记不同，$y$ 可以不同。

## 3. 判断题

| 小题 | 判断 | 原因 |
| --- | --- | --- |
| 1 | 错 | Q 是价值预测，不是概率，通常使用线性输出 |
| 2 | 对 | 终止后没有后续回报，$y=r$ |
| 3 | 错 | 目标网络由参数复制更新，不由优化器更新 |
| 4 | 对 | 连续状态可以输入网络，离散动作便于枚举最大值 |
| 5 | 错 | 自举目标在变化，需要独立评估策略效果 |
| 6 | 错 | Q-learning 是离策略方法，可以使用旧行为策略的数据 |

## 4. 最优决策与折扣临界值

终止动作的价值直接为：

$$
Q^*(S_0,\text{领取})=4,\quad Q^*(S_1,\text{安全})=10,\quad Q^*(S_1,\text{危险})=-6.
$$

继续探索的价值：

$$
Q^*(S_0,\text{探索})=-2+0.8\max(10,-6)=6.
$$

所以最优顺序为“继续探索 → 安全出口”。

临界值由 $-2+10\gamma=4$ 得到 $\gamma=0.6$。在通常 $0\leq\gamma<1$ 范围内：

- $0.6<\gamma<1$：继续探索更优。
- $0\leq\gamma<0.6$：立即领取更优。
- $\gamma=0.6$：起点两个动作并列。

本题回合有限，若允许 $\gamma=1$，此时也选择继续探索。

## 5. 两个网络与连续更新

**第一步：安全出口。** 已终止：

$$
y=10,\quad\delta=10-6=4,\quad q_{\text{新}}=6+0.5\times4=8.
$$

目标安全出口值仍为 5。

**第二步：继续探索，不同步。**

$$
y=-2+0.8\max(5,-1)=2.
$$

$$
\delta=2-1=1,\quad q_{\text{新}}=1+0.5\times1=1.5.
$$

**第三步：当前动作。** 在线起点为 `[3, 1.5]`，所以选择立即领取。

**第四步：同步后重新训练探索。** 此时目标安全出口为 8，危险出口为 −2：

$$
y=-2+0.8\max(8,-2)=4.4.
$$

$$
\delta=4.4-1.5=2.9,\quad q_{\text{新}}=1.5+0.5\times2.9=2.95.
$$

此时 $2.95<3$，仍选择立即领取；不能因为真实最优动作是探索，就认为当前网络必须已经选它。

**第五步：最终网络。** 最后一次梯度更新后没有再次同步：

| 状态、动作 | 在线网络 | 目标网络 |
| --- | ---: | ---: |
| $S_0$，立即领取 | 3 | 3 |
| $S_0$，继续探索 | 2.95 | 1.5 |
| $S_1$，安全出口 | 8 | 8 |
| $S_1$，危险出口 | −2 | −2 |

## 6. 批量目标、损失与导数

$$
y_A=2,\qquad y_B=-1+0.9\times5=3.5.
$$

$$
\delta_A=2-1=1,\qquad\delta_B=3.5-2=1.5.
$$

$$
L=\frac{1}{2\times2}(1^2+1.5^2)=\frac{3.25}{4}=0.8125.
$$

$$
\frac{\partial L}{\partial q_A}=-\frac12\times1=-0.5,\qquad
\frac{\partial L}{\partial q_B}=-\frac12\times1.5=-0.75.
$$

这些是对网络输出的导数，仍需链式法则才能得到对参数的梯度。

## 7. 真正终止与时间截断

1. 真正终止：$y=1$。
2. 外部时间限制截断：$y=1+0.9\times6=6.4$。
3. 两者都结束采样回合；$d$ 分别记录 1 和 0。必须保存重置前的下一状态。

## 8. 探索概率

贪心分支概率为 0.8，随机分支每个动作分到 $0.2/4=0.05$。

$$
P(\text{贪心动作})=0.8+0.05=0.85.
$$

每个非贪心动作概率为 0.05。概率之和 $0.85+3\times0.05=1$。随机探索也可能选到贪心动作，因此 $1-\epsilon$ 只是进入贪心分支的概率。

## 9. 张量形状

| 张量 | 形状 |
| --- | --- |
| `states` | `[32, 4]` |
| `online(states)` | `[32, 2]` |
| `actions` | `[32]` |
| `actions.unsqueeze(1)` | `[32, 1]` |
| `gather(1, ...)` 输出 | `[32, 1]` |
| `.squeeze(1)` 后 | `[32]` |
| 训练目标 | `[32]` |

`[32, 1]` 与 `[32]` 直接相减会广播为 `[32, 32]`，每个预测都与多个目标交叉相减，破坏样本对应关系。应让二者同为 `[32]`，或同为 `[32, 1]`。

## 10. DQN 与 Double DQN

标准 DQN 由目标网络取最大值：

$$
y_{\text{DQN}}=1+0.9\max(6,4)=6.4.
$$

Double DQN 由在线网络 `[5, 7]` 选择动作 1，再由目标网络评价该动作得到 4：

$$
y_{\text{Double}}=1+0.9\times4=4.6.
$$

Double DQN 可以缓解高估偏差，但不意味着任意样本上的目标都一定更低或更准确。

## 11. 宝箱实验参考与验收

运行方式见 [代码说明](code/README.md)。建议分别保存不同种子的输出目录：

```bash
python DQN/code/train.py --env treasure --seed 0 --output runs/treasure_seed0
python DQN/code/train.py --env treasure --seed 1 --output runs/treasure_seed1
python DQN/code/train.py --env treasure --seed 2 --output runs/treasure_seed2
python DQN/code/train.py --env treasure --gamma 0.3 --seed 0 --output runs/treasure_gamma03
```

默认 $\gamma=0.9$ 时，理论结果为：

- 起点 Q 值 `[3, 6.2]`，山洞 Q 值 `[8, −4]`。
- 贪心顺序“进山洞 → 开宝箱”。
- 评估普通回报为 7，折扣回报为 6.2。

$\gamma=0.3$ 时：

$$
Q^*(S_0,\text{山洞})=-1+0.3\times8=1.4<3.
$$

因此起点 Q 理论值变为 `[3, 1.4]`，应拿金币，普通与折扣回报均为 3。山洞的两个终止动作理论值仍为 `[8, −4]`。

验收重点是策略正确、Q 估计接近理论值、评价口径一致。神经网络有限步优化、随机初始化、采样顺序、共享参数和目标滞后都会造成误差，不要求逐位等于理论数值。若未学会，先检查数据覆盖、终止屏蔽、张量形状和训练预算，而非直接写入理论答案。

## 12. Huber 损失

原代码使用 $\frac12\delta^2$。可以把损失行替换为：

```python
loss = torch.nn.functional.smooth_l1_loss(current_q, targets, beta=1.0)
```

在 `beta=1.0` 时，它与本讲阈值 1 的 Huber 损失一致。

| TD 误差 | 平方损失 $\frac12\delta^2$ | Huber 损失 |
| --- | ---: | ---: |
| 0.5 | 0.125 | 0.125 |
| 3 | 4.5 | 2.5 |

Huber 对大误差的梯度不再随误差线性增大。比较时固定网络、预算、种子列表与评估设置；报告多个种子的策略表现。两种损失的数值尺度不同，不能仅比较谁的损失数字更小；单次结果也可能由随机性造成。

## 13. 错误代码分析

1. 用 `terminated or truncated` 屏蔽自举，会错误处理单纯时间截断；回放池只存 `terminated` 作为该标记。
2. 标准 DQN 的下一状态值应来自目标网络，不能直接使用在线网络。
3. 没有屏蔽真正终止经验的未来价值。
4. 计算目标没有停止梯度，应使用 `with torch.no_grad():`。
5. 当前 Q 值应取经验中实际执行的动作，用 `gather`；不能对当前状态直接取最大值。
6. 反向传播前未清空梯度，梯度会累积。

修正核心片段：

```python
# dones 只表示 terminated；rewards、dones、current_q、targets 均为 [B]
with torch.no_grad():
    next_q = target_net(next_states).max(dim=1).values
    targets = rewards + gamma * (1.0 - dones) * next_q

current_q = online(states).gather(1, actions.unsqueeze(1)).squeeze(1)
loss = 0.5 * (targets - current_q).square().mean()
optimizer.zero_grad(set_to_none=True)
loss.backward()
torch.nn.utils.clip_grad_norm_(online.parameters(), max_norm=10.0)
optimizer.step()
```

目标网络仍需在完整循环中定期同步。梯度裁剪是本实验的稳定化措施；原片段没有裁剪不属于必然的算法错误。原片段未乘 $1/2$ 也不是算法错误，只会改变损失和梯度的缩放。

## 14. CartPole 报告验收

没有固定的唯一训练分数。合格报告应包含：

1. 环境和依赖版本、种子、训练回合与交互步数、超参数。
2. 每个种子的独立贪心评估结果，及跨种子的统计；区分“一次评估内的回合标准差”和“跨种子的均值标准差”。
3. 保存模型后用 `--evaluate` 重新加载，在同一组评估初始种子下核对回报。
4. 说明训练包含随机动作，评价使用 $\epsilon=0$；训练回报波动不能直接代表最终策略。
5. 如未达到期望，诚实记录结果并分析原因，不能用挑选最佳种子代替完整报告。
