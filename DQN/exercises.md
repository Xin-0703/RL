# DQN 课后练习

建议先独立完成，再查看 [参考答案](answers.md)。计算题统一采用 $\delta=y-q$；除特别说明外，平方损失为 $L=\frac{1}{2B}\sum_i(y_i-q_i)^2$。

## 一、概念题

### 1. 即时奖励与 Q 值

某动作的即时奖励为 −2，但其 Q 值为 5。这是否矛盾？请举一个两步奖励的例子说明。

### 2. 三个关键机制

分别说明经验回放、目标网络、$\epsilon$-greedy 解决什么问题。目标网络参数固定时，所有训练样本的目标值是否都相同？

### 3. 判断并解释

1. DQN 的输出必须经过 softmax，才能选动作。
2. 在真正终止的经验中，目标网络预测再高，也不应该加到目标中。
3. 目标网络与在线网络都需要优化器执行梯度更新。
4. DQN 可以直接处理连续状态输入，但标准形式要求有限离散动作。
5. 损失持续下降足以证明策略性能持续提高。
6. 经验池中的数据来自旧策略，因此不能用于 Q-learning。

## 二、计算题

### 4. 最优决策与折扣临界值

```text
S₀ ─立即领取 / +4→ 结束
S₀ ─继续探索 / −2→ S₁
S₁ ─安全出口 / +10→ 结束
S₁ ─危险出口 / −6→ 结束
```

1. $\gamma=0.8$ 时，写出四个最优动作价值和最优动作顺序。
2. $\gamma$ 在什么范围内应当继续探索？什么时候两个起点动作并列？

### 5. 两个网络与连续更新

本题使用独热输入、无偏置线性网络与普通 SGD，因此单样本更新为 $q_{\text{新}}=q+\alpha(y-q)$。不同状态、动作的参数相互独立。

取 $\gamma=0.8$，$\alpha=0.5$，使用第 4 题的环境：

| 状态、动作 | 在线网络 | 目标网络 |
| --- | ---: | ---: |
| $S_0$，立即领取 | 3 | 3 |
| $S_0$，继续探索 | 1 | 1 |
| $S_1$，安全出口 | 6 | 5 |
| $S_1$，危险出口 | −2 | −1 |

依次执行：

1. 训练“安全出口，奖励 +10，终止”，求 $y$、$\delta$、更新后的在线预测。
2. 暂不同步，训练“继续探索，奖励 −2，到达 $S_1$”，求 $y$、$\delta$、更新后的在线预测。
3. 此时用在线网络贪心选择，起点选择什么？
4. 同步目标网络，再训练同一条“继续探索”经验，求新目标和在线预测。
5. 写出最终两个网络的完整数值，特别注意最后一步是否发生同步。

### 6. 批量目标、损失与导数

$\gamma=0.9$，$B=2$：

| 样本 | $r$ | $d$ | 下一状态最大目标 Q 值 | 当前在线预测 $q$ |
| --- | ---: | ---: | ---: | ---: |
| A | 2 | 1 | 9 | 1 |
| B | −1 | 0 | 5 | 2 |

求两条经验的目标、TD 误差、批量损失，以及 $\partial L/\partial q_A$ 和 $\partial L/\partial q_B$。

### 7. 真正终止与时间截断

某条经验的奖励为 1，下一状态最大目标 Q 值为 6，$\gamma=0.9$。

1. `terminated=True` 时目标是多少？
2. `terminated=False, truncated=True`，且截断只来自外部采样时间限制，目标是多少？
3. 两种情况是否都需要结束当前采样回合？回放池的 $d$ 分别记录多少？

### 8. 探索动作的实际概率

共有 4 个合法动作，贪心动作唯一。$\epsilon=0.2$，随机分支在全部动作中均匀选择。

1. 选择贪心动作的总概率是多少？
2. 每个非贪心动作的概率是多少？
3. 为什么不能说“选择贪心动作的概率就是 $1-\epsilon$”？

### 9. 张量形状

批量大小为 32，状态维度为 4，动作数为 2。写出以下张量形状：`states`、`online(states)`、`actions`（一维动作编号）、`actions.unsqueeze(1)`、`gather` 后的张量、压缩后的当前 Q 值、训练目标。

如果当前 Q 值形状是 `[32, 1]`，目标形状是 `[32]`，直接相减会发生什么问题？

### 10. DQN 与 Double DQN

下一状态在线网络输出 `[5, 7]`，目标网络输出 `[6, 4]`。奖励为 1，$\gamma=0.9$，未终止。

1. 标准 DQN 的目标是多少？
2. Double DQN 的目标是多少？分别由哪个网络选动作、评价动作？

### 13. 检查实现错误

阅读下面的错误片段，至少指出五处问题，并给出修正思路：

```python
done = terminated or truncated
replay.append((state, action, reward, next_state, done))
next_q = online(next_states).max(dim=1).values
target = rewards + gamma * next_q
current = online(states).max(dim=1).values
loss = ((target - current) ** 2).mean()
loss.backward()
optimizer.step()
```

假设 `optimizer` 只包含在线网络参数，片段前没有清空梯度，也没有无梯度上下文；任务的截断只来自外部时间限制。
