# 策略梯度实验实测记录

验证日期：2026-11-24（Asia/Shanghai）。运行环境：Windows、Python 3.11.7，标准库。下列结果来自实际执行，详细命令见 [实验说明](README.md)；随机实验小数不作为跨平台固定输出要求。

## 1. 算法机制与导数

执行 `python -m unittest discover -s PolicyGradient/code -p test_reinforce.py -v`：**13 项全部通过**。

测试包括：softmax 平移与稳定性、对数概率有限差分、显式外层折扣、按回合而非步数平均、上升方向、枚举全部宝箱轨迹与随机单步结果、任意固定状态基线保持期望、历史基线冻结、当前样本基线反例、末批归一化、拒绝不完整轨迹、评价不修改策略、参数校验。

中心有限差分步长 1e-6，测试 logits 每行为 `[0.2,-0.3]`：

| 目标 | γ | 解析梯度与差分最大绝对差 |
| --- | ---: | ---: |
| bandit | 0.9 | 4.52814e-11 |
| treasure | 0.9 | 3.10406e-10 |
| treasure | 0.3 | 1.03469e-10 |

解析导数对 J 的检查与枚举采样估计的期望检查互相独立，避免只验证两个相同错误的更新公式。

## 2. 单步随机任务

每组训练 10,000 回合，批量 20，500 次参数更新，学习率 0.1，独立随机评价 5000 回合。动作成功概率 `[0.2,0.8]`，最优 J=0.8。

| 基线 | 种子 | 动作 1 概率 | 精确 J | 随机评价均值 | 回报标准差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| none | 0 | 0.981377 | 0.788826 | 0.780400 | 0.413976 |
| none | 1 | 0.980035 | 0.788021 | 0.785000 | 0.410822 |
| none | 2 | 0.981113 | 0.788668 | 0.790400 | 0.407023 |
| history | 0 | 0.981204 | 0.788722 | 0.780400 | 0.413976 |
| history | 1 | 0.979980 | 0.787988 | 0.785000 | 0.410822 |
| history | 2 | 0.982608 | 0.789565 | 0.790800 | 0.406737 |

两类方法均偏向优动作；有限随机评价与精确 J 有抽样差异。基线不是每个种子都带来更高最终 J，这些数据不支持“加基线必然更快或更好”的断言。

## 4. 固定策略方差比较

使用 `variance.py` 固定均匀宝箱策略，γ=0.9，每组 1000 个独立批次，每批 20 回合。两类估计使用相同轨迹；基线是已知解析 V `[1.9,2]`，不是训练的历史估计。真实梯度为 `[0.55,-0.55,1.35,-1.35]`。

| 种子 | 无基线坐标方差之和 | 解析 V 基线坐标方差之和 | 无基线平均梯度误差范数 | 解析 V 基线误差范数 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 0.673709 | 0.553764 | 0.018186 | 0.015697 |
| 1 | 0.700974 | 0.563761 | 0.051320 | 0.033490 |
| 2 | 0.688240 | 0.535899 | 0.011602 | 0.009357 |

在本任务固定分布下，三组都观察到解析 V 基线降低坐标方差之和。平均梯度误差仍不为零，因为批次数有限；本比较不能推导出任意历史基线都同样有效，也不能声称解析 V 是多步梯度总方差的理论最优基线。

## 5. 实测范围

共 16 组配置：12 组双环境/双基线/三种子训练、1 组低折扣训练、3 组固定策略方差比较。另完成 13 项机制测试。结果支持小型表格离散策略与本章公式；未实现神经网络策略、Actor-Critic、PPO、连续动作或大型环境性能评测。
